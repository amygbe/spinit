Spin It · the mark & the icon set

Line-drawn, stroke-only, round caps — the same hand as the existing logo. Because nothing is filled and the stroke is currentColor, one file works on every palette: the header sets color:var(--pop), a card sets color:var(--ink). Switch palettes above — nothing on this page is redrawn, it only inherits.

1 · The mark

Redrawn from design/logo-square.png. The swirl is generated as a helix — each turn widens by a constant rate — because a spiral that drifts is the one thing the eye reads as a mistake rather than as soft serve. Stroke weight is set to land on the same optical thickness as the PNG at 42px.

2 · How much colour the icons carry

The emoji are full-colour, so every card currently reads a little differently. Two ways to go, and the same drawing serves both — each icon's outline is one closed path, so it can be left hollow or flooded.

A · One ink

Every icon inherits the card's ink. Maximally calm, changes with the theme for free, and the flavour reads from the drawing alone.

B · Line + the recipe's swatch

Outline stays palette ink; the fill uses each recipe's stored swatch — the 18-colour field that is still saved but no longer drawn. Keeps the cards playful and gives that data a job again.

3 · Flavour icons

Broad enough to cover the emoji anyone would actually reach for on a Creami recipe — berries, orchard and tropical fruit, chocolate and cookies, bakery, nuts and grain, spice and drinks. Anything not in the set still falls back to the emoji, so a community recipe is never blocked on an icon existing. Icons carry their own colours where the real thing has one: a banana is yellow, a watermelon rind is green, an Oreo's cream is off-white — the recipe's swatch only tints the parts that are genuinely up for grabs.
